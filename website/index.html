See through solid walls with a $5 WiFi chip.

WiFi Sense extracts raw 802.11 Channel State Information (CSI) to detect human motion and respiration in complete darkness. No cameras. No radar. Just ordinary WiFi.

View Source Code Quick Start

Engineering at the Edge

Built for the Raspberry Pi 4 and ESP32-S3, bypassing standard WiFi limitations to extract raw physical layer data.

Sub-Millimeter Precision

Because the human body is mostly water, we reflect 2.4GHz signals strongly. By decomposing the sub-carrier covariance to establish a noise floor, the DSP isolates tiny Doppler shifts. A chest moving just 6mm during breathing is perfectly resolved at 0.13–0.7 Hz.

Total Privacy

No optical sensors. Operates in total darkness. Detects presence and movement without capturing identifiable images or audio.

Encrypted Link

CSI data is routed over an AES-128 encrypted nRF24 radio link to prevent the transfer from corrupting the 2.4GHz measurement band.

Real-time DSP Pipeline

The Raspberry Pi continuously forces a 100Hz UDP stream to the ESP32. It cleans the bytes into amplitude, tracks respiration peaks via harmonic summation, applies hysteresis, and streams a live WebGL 3D waterfall to your browser.

bash — install

$ git clone https://github.com/The-Masked-Bear/wifisense-pi

$ cd wifisense-pi && python3 -m venv .venv

# Install dependencies

$ ./.venv/bin/pip install -r requirements.txt

# Run the physics simulator without any hardware!

$ cd pi && ../.venv/bin/python -m wifisense --link synthetic
