Temperature and pressure come from the BMP280, humidity from the DHT22. The air quality figure is a gas‑only index: it uses the standard 0–500 AQI scale and category boundaries, but it is computed from the MQ135's CO₂‑equivalent reading alone. A regulatory AQI is dominated by PM2.5, which this sensor cannot measure at all — so a smoky room can still read Good here. The MQ135 is also a single resistance that responds to alcohol, smoke, ammonia and solvents alike, baselined against whatever the air happened to be at calibration. Trust the direction it moves, not the absolute number.

Delivery is measured from the sequence number the node stamps on every CSI frame, so a gap is a frame that provably left the node and never arrived — it is real loss, not a slow reader. Corrupted counts frames that arrived damaged and were rejected by the CRC, which protects correctness at the cost of throughput. On a radio link a single frame is split into several packets and survives only if every packet does, so fragment loss is the usual cause of frame loss; duplicates are auto‑ack retransmissions and are harmless. Counters are cumulative since this server started, except the node's own, which count from when the node last booted.
